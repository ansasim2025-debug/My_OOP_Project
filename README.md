## Description
MediCore is a Hospital Management System that supports three types of users: Patients, Doctors, and Admin. 
It manages appointments, prescriptions, billing, and medical records. All data is stored in and read from .txt files 
so it persists between program restarts. The GUI is built using SFML 3.0.0.

---

## How to Compile and Run

1. Open the project in Visual Studio
2. Make sure SFML 3.0.0 is linked in project properties
3. Make sure `manrope-bold.otf` is in the same folder as the executable
4. Make sure all `.txt` data files are in the same folder as the executable
5. Press Ctrl+F5 to build and run

---

## Data Files
- `patients.txt` — Patient records
- `doctors.txt` — Doctor records
- `admin.txt` — Admin credentials
- `appointment.txt` — Appointment records
- `bills.txt` — Billing records
- `prescriptions.txt` — Prescription records
- `security_log.txt` — Failed login attempts
- `discharged.txt` — Discharged patient archive
